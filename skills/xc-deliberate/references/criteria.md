# Criteria

Every rebuttal node loads this file before it writes a line, and the orchestrator loads it when it judges a finished conclusion before merging. It owns one question only: which sentences in a text are the user's thinking and which are the worker's thinking. What a worker may read is `references/inputs.md`, where material is filed is `references/records.md`, and how a conclusion reaches the document it argues about is `references/merge.md`.

## The line

The product of a debate is text that carries the user's thinking. A worker may sharpen that text, extend it, and argue against it, but the reasoning inside it has to be the user's.

The criterion is the source of each assertion, never its length.

> Can every newly written sentence be traced back to a component of the user's own words? If it cannot, it crosses the line, whether it is one clause or eight paragraphs.

Length is only a proxy. Two sentences carrying one key judgement the user never made are worse than eight paragraphs that unfold what the user did say.

The criterion governs the body text of the product. Headings, frontmatter, file layout and the round records are outside it.

## Compliant forms

An addition is compliant in one of two forms, and only these two.

The first annotates which component of the user's words the sentence comes from, specifically enough that a reader can find that component in the recorded words.

The second states in the sentence itself that it is an addition and asks the user to confirm it. It stays a proposal until the user answers.

An addition with neither annotation is overreach, however small it is and however obviously true it looks. The user cannot accept what was never marked as an addition, and a reader cannot tell an offered sentence from an asserted one.

## Why rebuttals are exempt

Objections are not bound by the criterion. A rebuttal worker reports what the user did not know, and a new fact by definition has no component in the user's words. Applying the criterion to objections forbids reporting new facts, and a debate that cannot report new facts collapses back into agreement: the worker can only restate the user's position in better words.

The exemption covers the objection as an argument. A fact that later enters the conclusion enters as an attributed sentence, and the criterion applies to it again there.

## What a rebuttal worker owes in exchange

It investigates. A rebuttal that only asks questions can draw out knowledge the user already holds; it cannot surface what the user does not know. Questioning is one stance among several, never the whole job.

It produces evidence. A claim it adds names a source that a reader can check.

It does not withhold an answer it already has. Holding a finding back to make the user work for it weakens the debate; the point is the user's decision, not the user's effort.

It says in its first line which of the two it is doing: challenging the reasoning, or reporting a new fact. Without that line the user cannot tell an objection from a briefing, and cannot tell whether the worker has understood the position or merely contradicted it.

## Who thinks and who types

Two independent questions decide what a product is: whose mental model it carries, and who writes it. Four combinations occur and three of them are legitimate.

| Mental model | The user writes | The worker writes |
| --- | --- | --- |
| The user's | The user drafts, the worker argues against the draft | The user directs, the worker transcribes |
| The worker's | The worst case | Full delegation |

Full delegation is not a failure. For a low-consequence, short-lived product that nobody has to take over, it is the correct answer.

The user directing while the worker types is legitimate for as long as the model stays with the user, which is exactly what the criterion protects: every passage that came from the worker is annotated or offered.

The worst case is the worker thinking while the user types. The product carries the user's name and the user's responsibility while the understanding stays elsewhere, and because the user's own hands produced the text the user trusts it more than it deserves. It looks like the most user-led arrangement and is the least.

This is also the boundary on polishing: changing wording carries a change of model, so a courtesy edit is not automatically a safe one.

## Attribution is judged per artefact

A debate produces several artefacts, and each is judged on its own. The conclusion may be the user's, a round summary its author's, a merge record the orchestrator's, all inside one work order with no inconsistency.

Mixed attribution is normal and needs no justification, because the judgement is about a document and not about a task.

This is a convention: nothing in the tree records who owns which artefact, no gate refuses a conclusion that crossed the line, and no check tells an annotated addition from an unannotated one. The criterion holds only where the writer applies it and the reader verifies it.
