# 核心设计

本页介绍 XC 的核心设计，并指向真正定义它的那份文档。

XC 核心设计是本项目对「XC 的核心是什么」的正式陈述：它给出五个维度共同依据的原则、不变量与判定标准，也是人与智能体在判断一次后续改动时共用的同一套参照。本页的作用是帮读者找到并理解那份陈述，而不是取代它。

权威核心设计是 `.xcoding/docs/core-design.md` 这份文档，其 H1 为 `Xcoding Workflow 核心设计`。它是本项目唯一规范的核心设计，只在工作坊自己的上下文仓库中的这一处维护。其他任何需要它的位置都只能按该路径与标题引用它，绝不复制成第二份，因此不存在需要同步、会各自漂移的副本。对该文档的任何调整、改进或变更，都必须在生效前先取得用户确认。

本概览说明核心设计位于何处，以及如何把它与其余公开文档一起使用。它不定义核心设计，也刻意不复述其内容：本页与权威文档如有出入，一律以权威文档为准。

若要了解周边背景，可阅读[架构](architecture.md)了解规范源与所有权边界，阅读 [Workshop 与 feature](workshops-features.md)了解第一个维度所依据的 workshop、work order 与 feature 基线，并阅读[演进工作流](../workflows/evolving.md)了解如何对工作流本身做一次慎重的变更。
