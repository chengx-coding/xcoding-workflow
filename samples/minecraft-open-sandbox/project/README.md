# Cubewood — a small Minecraft in the browser

Cubewood is a playable, offline 2D sandbox inspired by Minecraft. Open `index.html` in any modern
browser and play: dig, build, craft, light the dark, watch the sun go down, and come back tomorrow
to the same world.

There is **no build step, no package manager, no external library, no font or image download, and no
network access at runtime**. Every texture, sound and world is generated by the code in this
repository. It works straight from `file://`.

## Play

1. Open `index.html` by double-clicking it (or `file:///…/index.html` in a browser).
2. Click **Play now**. A task list guides the first ten minutes; the HUD buttons open the same
   systems from the mouse.
3. Your world saves automatically to this browser. Use **Save (F2)** to save immediately, or
   **Menu → Export save** to keep a file copy.

The first screen offers **Play now**, **Open the guide** and **New world** — no keyboard legend is
required to get started, and every primary system also has a visible HUD button.

## Controls

| Input | Action |
| --- | --- |
| `A` / `D` or `←` / `→` | Walk left and right |
| `W` / `Space` / `↑` | Jump (coyote-time forgiving, 1-tile ledges are climbed automatically) |
| Hold **left click** | Mine the highlighted block; cracks and a progress ring show the work |
| **Right click** | Place the selected block next to a neighbour, inside reach |
| `1` – `9`, or click a hotbar slot | Select a hotbar slot |
| `E` | Inventory |
| `C` | Crafting |
| `Q` | Show or hide the quest tracker |
| `H` | Guide and controls |
| `B` | Backdrop mode: show before/after ghosts of recent edits |
| Mouse wheel, `+` / `-` | Zoom the view (0.6× – 2.5×) |
| `T` | Wait three hours and watch the sky change |
| `Ctrl`+`Z` / `Ctrl`+`Y` | Undo / redo the last edit |
| `F2` | Save now |
| `M` | Mute or unmute sound |
| `Esc` | Close panels, or open the menu |

## What is in the world

- **Seeded worlds** (192 × 96 tiles) with rolling hills, plains/forest/desert/rocky bands, caves,
  coal and iron veins, trees and flowers. The seed is shown and editable in **Menu → New world**.
- **Mining and building** with per-block hardness, tool classes (pickaxe, axe, shovel), harvest
  tiers, drops, block-break particles and placement rules (reach, support, no self-overlap).
- **Crafting** with 11 recipes that unlock as you gather new materials: planks, sticks, torches,
  glass, wooden/stone/iron pickaxes, axes and shovels. Crafting consumes the listed ingredients.
- **A day/night cycle** (4 minutes) with a sky that changes colour, sun and moon, stars and a
  glowing moonlit horizon.
- **Light**: skylight falls off underground, torches light caves with a warm glow, and the world
  gets genuinely dark at night.
- **Survival touches**: hearts, fall damage, respawn at spawn, and a task chain that rewards
  gathering, crafting, building, lighting, digging and surviving the night.

## Saving

- The world, player position and health, inventory, hotbar, time of day, day count, quest progress
  and settings are saved as one versioned JSON envelope.
- Saves are written automatically every 12 seconds, on page hide and on exit; `F2` saves now.
- Save data lives in this browser's local storage. If local storage is unavailable (some browsers
  block it on `file://`), Cubewood keeps the session in memory and tells you to use
  **Menu → Export save** instead of silently losing work.
- **Menu → Export save** downloads `cubewood-dayN.json`; **Menu → Import save** restores a file.
  Both work offline.
- **Menu → New world** generates a fresh world from a seed and saves it.

## Backdrop: before/after by design

Every change the player makes leaves a reviewable trace:

- Each mine/place records the block before and after; the **Backdrop** panel shows the two states
  side by side with labels (for example `Grass → Air`), and **Backdrop mode (B)** overlays dashed
  ghosts of recent edits in the world.
- **Mode** changes (`Build` ↔ `Backdrop`), **time** changes (day → dusk → night), and **viewport**
  changes (zoom or window resize) each raise their own before/after pulse.
- The minimap keeps the **previous viewport** outlined for a few seconds after a zoom or resize so
  the change of view is visible, not just remembered.

## Accessibility and quality-of-life

- Buttons are real DOM buttons with visible focus, labels and `aria-pressed` states; panels are
  dismissible with `Esc` and trap initial focus.
- The HUD is responsive; on narrow screens the action buttons move above the hotbar and the
  minimap hides.
- Sound is procedural, starts only after a gesture, and is muted persistently.
- The game keeps running while panels are open only in the sense of rendering; gameplay input pauses
  while a panel or the welcome overlay is open.

## Checks

From the project root:

```console
node --test "tests/**/*.test.js"
python tools/page_check.py
```

`page_check.py` is the original seed check: it verifies the page shell, that every referenced asset
is local, that no network reference exists in page-served files, that the status marker is the
expected green, and that the canvas is not blank.

A second, richer browser check covers real interaction and visual state:

```console
python tools/browser_check.py --out .xcoding/work-orders/<id>/artifacts/verification/browser
```

It runs the in-page self-test with real Chrome (DOM clicks, real pointer mining/placement, real
keyboard movement, before/after pulses, save/restore), proves save persistence across two browser
launches with a shared profile, and captures the scene screenshots (`welcome`, `day`, `night`,
`backdrop`, `zoom1/zoom2`, `cave`, `inventory`, `crafting`, `guide`) with pixel checks that paired
states really differ.

Logic is covered by Node's built-in test runner: world generation and RLE saves, physics and
collision, mining/tool rules, placement, inventory, crafting, tasks, backdrop history, save
envelopes and storage fallback.
