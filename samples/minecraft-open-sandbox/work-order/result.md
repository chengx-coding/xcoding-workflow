# Result — Cubewood, a playable offline 2D sandbox

## Outcome

**Completed.** The seed shell became a playable game: open `index.html` from `file://`, click
**Play now**, and dig, build, craft, explore generated worlds, light caves, survive nights and keep
your world across reloads. No build step, no external library, font, image or network request was
added; every texture, sound and world is generated by local code.

All four implementation units, both verification nodes and the full managed lifecycle completed.
The change-report stage was waived by the user, so no report was produced.

## What was delivered

| Capability | Delivered |
| --- | --- |
| Movement and physics | Walk, jump with coyote time and jump buffering, AABB collision, ledge climb, fall damage, respawn |
| Seeded world | 192×96 worlds with plains/forest/desert/rocky bands, caves, coal and iron veins, trees, flowers, clear spawn |
| Mining | Hold-to-mine with hardness, tool classes/tiers, cracks, progress ring, particles, drops and "needs a pickaxe" feedback |
| Building | Reach/support/overlap rules, ghost preview, placement consumption, undo/redo |
| Inventory and crafting | Counted items, 9-slot hotbar, 11 recipes that unlock with gathered materials, one-click crafting |
| Day/night and light | 4-minute cycle, keyframed sky, sun/moon/stars/clouds, skylight falloff, torch flood-fill light and glow |
| Save progress | Versioned RLE JSON envelope in local storage, autosave + F2 + save on exit, memory fallback, export/import, new world by seed |
| First-run affordance | Welcome with Play/Guide/New, seven visible HUD buttons, quest tracker, hover hints, toasts |
| Visual-state backdrop | Before/after panel for edits, world ghosts in backdrop mode, before/after pulses for mode/time/viewport, minimap viewport trail |
| Progression | 8-step quest chain with rewards, tool tiers, day counter, persistent state |
| Controls documentation | 16-control in-product guide and a full README controls table |

## Residual risks and limitations

- Save export/import is unit-tested and wired, but a real browser download/upload is a manual path
  not automated in the headless evidence.
- Audio quality is not machine-assessable; only the gesture-gated state path is checked.
- Performance timings read 0 under headless virtual time; the structural cost is bounded to the
  visible tiles and a full 18,432-tile relight per edit, with no observed failure.
- All browser evidence is Chrome 156; Firefox/Safari and the <780 px layout were not run.
- At night the unlit underground is very dark by design; torches are the remedy.
